# إعادة تصور تجربة مشواري — 24 أكتوبر 2026

أساس العمل هو الالتزام `ab6149c` الذي يتضمن إصلاحات المراجعة السابقة، وليس الرجوع إلى نسخة ما قبل تلك الإصلاحات. العمل محصور في Android؛ لا تغيير لمشروع الويب أو ملفات الإصدارات المنشورة.

## التحول

اختير اتجاه **أطلس شخصي**: صفحات تحريرية عاجية/حبرية، نحاس للإجراءات، وتسلسل أوضح للمحتوى. الهوية ليست تبديل ألوان فقط:

| المساحة | قبل | بعد |
|---|---|---|
| التنقل | مساعد ضمن الشريط، والخريطة من أدوات فرعية | خريطة وجهة رئيسية، والمساعد إجراء ثابت أعلى الصفحة؛ شريط جانبي على النوافذ الواسعة |
| الرئيسية | بطاقة طويلة وثلاث بطاقات اختصارات وشبكة مقاييس | لوحة انطلاق أفقية مختصرة، أرقام الفترة في صفحة واحدة، وإدخالات المشاوير الزمنية |
| تفاصيل المشوار | خريطة وأدوات ومقاييس وتوقفات في قائمة واحدة طويلة | ملخص ثم ثلاثة تبويبات: المسار، الوقت والتكلفة، التوقفات والزيارات |
| الخريطة | ضمن قائمة قابلة للتمرير بارتفاع ثابت وأدوات كثيرة مكشوفة | مساحة ثابتة للسحب، بحث فوق الخريطة ولوحة أدوات سفلية ذات تبويبين |
| الصوتيات | فلاتر وقائمة مباشرة | رف استكمال من المواضع الفعلية، ثم التصفح؛ مشغّل بعنوان ومصدر وغلاف وأدوات عند الطلب |
| المحفظة | نسخة أخرى من بطاقة الرئيسية | بيان مالي مستقل، إضافة مصروف والوصول للحوالات، مع بقاء سجل/تحليل |
| المزيد | قائمة طويلة بكل الأدوات | خمس مجموعات قابلة للفتح وبحث مباشر، والنماذج والنسخ الاحتياطي بارزان |

[مواصفات النظام البصري](DESIGN_SYSTEM.md) تسجل الألوان والمكونات والمراجع التي قُرئت. الرسوم الجديدة محلية ومكتوبة بالكود؛ لا أصول منسوخة ولا خطوط أو اعتماديات جديدة.

## الحفاظ على الوظائف والبيانات

- `sa.rihla` و`sa.rihla.next`، اسم التطبيق، الإصدار `64 / 6.4` والتوقيع لم تتغير.
- مخططات المشاوير/الصوتيات/الحوالات باقية `7 / 2 / 1`. لا تعديل لـ DAO أو مستودعات البيانات أو منطق التتبّع أو استيراد الرسائل أو النسخ الاحتياطي أو معالج الصوت.
- جميع مفاتيح صفحات التنقل محفوظة، بما فيها أوامر المساعد. تبويبات وفلاتر المكتبة والقوائم والمفضلة والمواضع والاستيراد والتصدير وأوضاع الصوت والأدوات اليدوية محفوظة.
- بيانات الخريطة ومصدرها وأدوات فحص النقاط والجزء والتوقفات والحفظ والمشاركة محفوظة. أُضيف قصّ لحدود عرض AndroidView حتى يبقى الرسم داخل مساحة الخريطة ولا يغطي ما حولها؛ لا تغيير لحساب الإحداثيات أو المسار.
- لا إذن جديد، ولا اتصال شبكي لبيانات شخصية، ولا حذف بيانات أو إعادة تسمية ملفات. كل أمثلة الصور والاختبارات مصطنعة.

## التحقق البصري والوظيفي

الصور أدناه من **الرسم الفعلي لـ Compose وAndroidView عبر Robolectric Native Graphics، SDK 35**، على مقاس هاتف 412×915dp وكثافة 3. ليست نماذج صور مولدة. التُقطت النسخة السابقة قبل تغييرات الواجهة، وأُعيد تصويرها بنفس تجهيز بيانات الاختبار وخدمة الصوت المستخدمة للنسخة الجديدة. تختلف ساعة التقاط المشوار بين التشغيلين. لا تثبت هذه الصور الأداء على جهاز حقيقي.

نتائج التشغيل المحلي النهائي (الكود نفسه بعد آخر تعديل للواجهة):

- `:app:testClassicDebugUnitTest :app:testNextDebugUnitTest`: **228 اختبارًا لكل نسخة، 456 تنفيذًا، صفر فشل/خطأ/تجاوز**. تشمل 220 اختبارًا قائمة و8 اختبارات تجربة جديدة لكل نسخة.
- `:app:lintClassicRelease :app:lintNextRelease`: **صفر أخطاء و49 تحذيرًا سابقًا لكل نسخة**. قورنت هويات التحذيرات ورسائلها وتكرارها بتقرير الالتزام `ab6149c`؛ لا تحذير جديد ولا كبت جديد.
- `:app:assembleClassicRelease :app:assembleNextRelease`: **نجاح**. نُفذت الأهداف الستة معًا، وانتهى آخر تشغيل بـ `BUILD SUCCESSFUL in 5m 12s`.
- `python3 -m unittest discover -s android/tools -p 'test_*.py'`: **15 اختبارًا ناجحًا**. `verify_schema.py`: نجاح الترحيلات القديمة والحذف المتسلسل وحفظ المصروفات؛ لا ترحيل أو مخطط جديد.
- فُحصت هوية APK المحلي وشهادة توقيعه ومطابقة versionCode/versionName وminSdk مع إصدار 6.4 المنشور لكل حزمة. اجتاز `zipalign` وفحص الأصول؛ حزمة خرائط السعودية والمكتبات الأصلية الخمس مطابقة بايتًا للإصدار السابق. لا ملفات توقيع داخل APK.
- مقارنة Git تؤكد بقاء ملفات البيانات والتتبّع والنواة والمخططات وmanifest والبناء والتوقيع ومشروع الويب والإصدارات دون تعديل. التغييرات في Android فقط.
- توجد تحذيرات Kotlin/Gradle قديمة عن إهمال بعض الأيقونات وTabRow وميزات Gradle؛ لم تُضَف اعتماديات أو تكتمات لمعالجتها ضمن إعادة التصميم.

أحجام APK المبني محليًا (غير منشور): classic: 102,431,019 بايت؛ next: 102,431,031 بايت. الصور في هذا التقرير من بيانات اختبار فقط. بعض لقطات تفاصيل المشوار تعرض تهيئة الخريطة؛ لقطة الخريطة الرئيسية تنتظر اكتمال رسم بيانات البلد.

إعادة توليد صور التجربة اختياريًا:

```sh
cd android
RIHLA_DESIGN_CAPTURE_DIR=/tmp/mashwari-design/current ./gradlew :app:testClassicDebugUnitTest --tests sa.rihla.design.ExperienceTest
```


ظهر في فحص PR الموازي سباق في اختبار الاعتماد السابق `ReviewUiTest`: تحديث الأسماء في التخزين قد يسبق إعادة تمكين زر الحفظ على Main. عُدّلت مزامنة الاختبار ليصرف حلقة الواجهة وينتظر تمكين الحفظ قبل الضغط التالي، مع بقاء تأكيد رسالة النجاح والاسمين دون تغيير. لا تعديل لمنطق الحوالات أو تمديد للمهلة أو حذف لتأكيدات الاختبار.

اختبارات `ExperienceTest` الثمانية تغطي التنقل وتبويبات التفاصيل وتصفية المفضلة، وصول النماذج وبحث الأدوات، بقاء اختيار القياس عند إغلاق لوحة الخريطة وظهور فاحص النقطة أولًا عند اختيارها، الوضع الداكن، تكبير الخط 2.0، شريط التنقل الجانبي على 900dp، وتباين النصوص الأساسية 4.5:1 أو أكثر. الاختبارات القائمة لم تُحذف؛ عُدّلت تسميات ومسارات الوصول التي تغيّرت فعليًا، وبقيت تأكيدات الوظائف.

## حدود العمل

- لا محاكي Android أو هاتف متصل في هذه البيئة. لم يُختبر RedMagic 11 Pro ميدانيًا، ولم يُقَس استهلاك البطارية أو سرعة الإطارات أو دقة GPS أو جودة الصوت. اختبارات الصوت القائمة تستخدم خدمة التشغيل وبيانات اختبار، وليست تجربة سماع بشرية.
- المحاور الرئيسية أُعيد تركيبها، بينما بقيت نماذج التحرير المتقدمة وصفحات تدريب المساعد وتقارير التشخيص بتخطيطها الوظيفي مع استفادتها من الهوية والمكونات المشتركة. لم تُعَد كتابة هذه الوحدات.
- أُبقيت قاعدة بيانات الخرائط والرسم الجغرافي كما هما؛ تحسين تصادم أسماء الأماكن ومحتوى الخريطة نفسه خارج إعادة التصميم هذه.
- لا رفع لرقم الإصدار، ولا نشر APK جديد أو دمج تلقائي. فرع التصميم مبني على فرع إصلاحات المراجعة كي لا تفقد الإصلاحات السابقة.
