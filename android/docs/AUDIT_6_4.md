# فحص التطبيق وإصلاحات 6.4

شمل الفحص مسارات التتبع والبدء التلقائي والخرائط وتحليل الخطوط، شراء SMS وحوالات
الوالد، مكتبة الصوتيات والتشغيل والتنظيم، المساعد والنماذج، وترقيات قواعد البيانات
والاستعادة. روجعت الشيفرة والحالات الحدية، ثم أضيفت اختبارات للمشكلات المثبتة؛
هذا لا يعني إثبات غياب كل عيب ممكن على جميع الهواتف.

## الإصلاحات

| المجال | المشكلة | السلوك بعد الإصلاح |
|---|---|---|
| الحوالات | استعادة سجل من مصدر آخر قد تزيد مجموع إيصال موجود | فحص التكرار عند الدمج، مع حفظ الصف للمراجعة وقرارات المستخدم الحالية |
| ملفات الحوالات | الكسور في مبلغ الهللات أو قرار المراجعة كانت تُقص إلى عدد صحيح، وطابع الرسالة المستقبلي مقبول | رفض الملف غير الصالح قبل أي تغيير، مع قبول الأعداد الصحيحة فقط والتحقق من الوقت |
| الأماكن المؤقتة | انتهاء التفعيل أثناء البقاء داخل المكان قد يُفهم كمغادرة | انتهاء التفعيل لا ينشئ ذهابًا وهميًا للجامعة |
| الأماكن المؤقتة | حالة التفعيل قد تتأخر حتى تحديث اليوم، والتحليل الطويل لا يوقف المسح الجاري سريعًا | تحديث عند موعد الانتهاء وفحص الإلغاء أثناء مسح النقاط وبناء التحليل |
| جودة التتبع | بعض الحواف المعلّمة «غير مؤكدة» لا تظهر كانقطاع في التقرير | احتساب عدم اليقين حتى دون علامة فصل إضافية؛ لا تعديل للنقاط أو تخمين لمسافة مفقودة |
| استيراد الصوتيات | الإلغاء قد يُعامل كفشل ملف ثم يستمر الاستيراد | توقف عند الإلغاء بين الملفات وأثناء تعداد المجلدات والهاتف؛ يحتفظ بما اكتمل |
| استعادة الصوتيات | مكتبة بلا مقاطع وبها مجلدات افتراضية قد تُعتبر فارغة | رفض استبدال أي مكتبة بها بيانات، بما فيها المجلدات |
| استعادة المشاوير | المنزل المستعاد قد لا يسجّل سياجه حتى إعادة الضبط | إعادة تسجيل سياج المنزل بعد الاستعادة وفق إعداد التتبع الحالي |
| الملفات المنقولة | قائمة التشغيل قد تبقى مرتبطة بمواقع الملفات قبل التنظيم الفعلي | تحديث روابط القائمة من المكتبة مع حفظ ترتيبها وموضع التشغيل وأوضاعه |
| جاهزية الرسائل | الاعتماد على إذن الإشعارات وحده يعرض رفضًا رغم تفعيل استقبال SMS | احتساب مسار استقبال SMS المباشر ضمن الجاهزية |

لم تتغير مخططات المشاوير (7) أو الصوتيات (2) أو سجل الحوالات (1). تبقى الملفات
الأصلية والمشاوير وقرارات المراجعة محفوظة. التحديث يحتفظ بهوية كل نسخة وتوقيعها.
التكرار المحتمل الذي يعتمده المستخدم صراحة كعملية مستقلة يظل محسوبًا؛ لا يُلغى
قراره تلقائيًا. لا يعيد الإصلاح تغيير قرارات أو صفوف مستوردة قبل هذا التحديث.

## حدود الفحص

فشلت سبع حالات رجعية جديدة على الشيفرة قبل إصلاحها، وأضيف اختبار ثامن لإلغاء تحليل المكان المؤقت. توجد اختبارات قبل الإصلاح وبعده، واختبارات Android للرسم والتشغيل، وفحص
ساكن وبناء للنسختين وفحص توقيع وتوافق APK وأدوات للترقيات والنسخ الاحتياطي.
النتائج النهائية والأعداد في [تقرير التحقق](../VERIFICATION.md).

لم يتوفر هاتف RedMagic 11 Pro أو صندوق رسائلك. لم يُختبر قيادة فعلية أو استهلاك
بطارية ميداني أو أداء كل صيغة صوتية أو تنفيذ النماذج الكبيرة على الهاتف. تعتمد
أذونات الخلفية وتسليم SMS وخدمات الكلام على النظام وإعداداته. لا يسترجع التطبيق
رسائل محذوفة من البنك، ولا تعالج اختبارات المحاكاة هذه الحدود.
