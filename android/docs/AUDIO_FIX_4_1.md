# إصلاح تشغيل الصوت — مشواري 4.1

يعالج هذا التحديث خللًا أُعيد إنتاجه في كود معالج اتساع الستيريو، ويمكن أن
يوقف المقاطع الثنائية حتى عندما تكون قيمة التأثير صفرًا. ثبّت 4.1 فوق النسخة
الحالية دون حذف التطبيق أو مسح بياناته؛ لا تحتاج إعادة إضافة المقاطع لهذا الإصلاح.
اسم الحزمة والتوقيع محفوظان، وقاعدة المشاوير تبقى بالإصدار 6 وقاعدة الصوتيات 1.

## السبب وإثبات الإصلاح

Media3 يمرر أحيانًا `AudioProcessor.EMPTY_BUFFER` المشترك عند تجهيز سلسلة
المعالجة أو تفريغها. المعالج كان يستدعي `replaceOutputBuffer(0)` ثم
`output.put(inputBuffer)`، وفي الحالة الأولى يكون المدخل والمخرج نفس الكائن.
Java ترفض نسخ المخزن إلى نفسه حتى عندما يكون فارغًا، فيحدث
`IllegalArgumentException: The source buffer is this buffer`.

أُعيد إنتاج الاستثناء قبل الإصلاح باختبار `DefaultAudioSink` الفعلي مع معالج
المشروع، وليس باستدعاء المعالج منفردًا ببيانات غير فارغة. الإصلاح يتجاهل المدخل
الفارغ قبل تخصيص المخرج، مع الاحتفاظ بنصف إطار الستيريو إن كان ينتظر عينة أخرى.

الاختبارات الجديدة تشمل:

- المخزن المشترك الفارغ قبل الصوت وبين جزأي إطار، والتأثير عند صفر وعند أقصى قيمة.
- انتقال PCM الستيريو عبر `DefaultAudioSink` إلى `AudioTrack` ومقارنة عدد البايتات
  المستلمة، مع تأثير الاتساع وبدونه. الاختبار نفسه كان يفشل قبل إصلاح المعالج.
- مقطع WAV اصطناعي يُقرأ من `content://` عبر خدمة التطبيق وExoPlayer ومستخرج WAV
  حتى الإخراج؛ ويتعافى المقطع نفسه عند توفر الملف بعد خطأ قراءة وإعادة المحاولة.
- رسائل مستقلة لأخطاء الأذونات والقراءة والترميز والإخراج والخطأ الداخلي، مع رمز
  رقمي للتشخيص دون تسريب مسار الملف أو URI أو نص الاستثناء. إعادة المحاولة تمسح
  التنبيه القديم عندما يزيل المشغل الخطأ، حتى دون الانتقال إلى مقطع آخر.

## حدود التحقق

أُعيد إنتاج خلل يناسب فشل المقاطع الثنائية بالصورة، لكن الصورة وحدها لا تثبت
أن هاتفك لم يواجه سببًا إضافيًا؛ النسخة السابقة كانت تعرض نفس التنبيه لكل الأخطاء.
التجربة هنا محاكاة Android على JVM، وليست قياسًا للصوت عبر سماعات RedMagic.
اختبار WAV لا يثبت دعم كل ترميزات AAC/MP3 أو توافق كل مزودي ملفات الهاتف.
إذا ظهر خطأ بعد التحديث، أرسل رمز الخطأ الجديد وطريقة إضافة الملف؛ سيحدد مرحلة
الفشل بدل افتراض أن الملف محذوف أو أن الإذن مسحوب.

تظل مكتبة الصوتيات محلية وقوائمها ومواضعها محفوظة، والتتبع والمصاريف والخرائط
وقواعد بياناتها لم تُغيَّر في هذا الإصلاح. [دليل المكتبة](AUDIO_4.md).
