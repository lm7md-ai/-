# حزمة أدوات الخريطة

إضافة واجهة فوق حسابات أجزاء التوقف الموجودة، دون تغيير محرك التتبع أو البيانات أو المخططات أو هوية النسختين. يبقى رقم الإصدار 6.5 / 65 كما طُلب سابقًا؛ هذه ملفات بناء محلية جديدة وليست إصدار GitHub منشورًا.

## المتاح

- أدوات مباشرة للموقع الحالي ومتابعة آخر نقطة وقائمة التوقفات مع أوقات ومدد التوقف.
- اختيار المشوار الجاري مباشرة من تسجيل آخر، واحتواء المسار بعد تحميل نقاط المشوار المختار.
- توسيع مساحة الخريطة بإخفاء لوحة المشوار، والعودة بزر واضح أو زر الرجوع في الهاتف.
- وضع قياس يترك الخريطة متاحة للمس، مع تراجع عن نقطة ومسح وإنهاء. إنهاء الوضع يحتفظ بالنقاط حتى يمسحها المستخدم؛ القياس مباشر ولا يمثل طول الطريق.
- عرض حالة المشوار ووقت آخر نقطة؛ آخر نقطة مسجلة ليست تحديدًا حيًا مضمونًا.
- تحديث نتيجة البحث وحالة فشله على خيط الواجهة بعد قراءة بيانات البحث في IO.

## التحقق وحدوده

اختبارات واجهة Robolectric Native Graphics تتحقق من زيادة مساحة الخريطة عند التوسيع، وإضافة نقاط القياس والتراجع والمسح والإنهاء، وفتح قائمة توقفات محفوظة ثم إظهار الجزء المحدد دون حوار يحجب الخريطة. الاختبارات القديمة حُدّثت لتوافق عودة المستخدم من لوحة الأدوات إلى الخريطة عند بدء القياس. كشفت الاختبارات مساحة لمس صفرية في أول تنفيذ لشريط القياس، وصُححت قبل التسليم.

الفحص الشامل المطلوب: اختبارات النكهتين، lintClassicRelease وlintNextRelease، assembleClassicRelease وassembleNextRelease. نتائج الفحص وتوقيع APK وأحجام الملفات وبصماتها محفوظة بجانب ملفات التنزيل في BUILD.json وSHA256SUMS.txt. تتم مقارنة أصول المحتوى والمكتبات الأصلية بملفي 6.5 السابقين؛ ملفات baseline profiles المشتقة من الكود تتغير طبيعيًا مع تغيير التطبيق.

لا إثبات لتكامل التطبيق على هاتف RedMagic فعلي في هذه البيئة. لا قياس جديد للبطارية أو دقة GPS أو سلوك قيود الخلفية أو قراءة رسائل حقيقية. الاختبارات لا تمثل ضمانًا أن كل الأجهزة والخدمات ستعمل دون عيب، ولا تعني اكتمال كل إضافة ممكنة للتطبيق. لا تغييرات للويب أو الإصدارات القديمة أو المفاتيح أو المخططات أو الأذونات.

ملفات التنزيل المحلية لهذه الحزمة موجودة في /workspace/rihla-artifacts/map-tools-final. لا تستخدم ملفات التجربة السابقة للحصول على الأدوات الجديدة. ثبّت نفس النكهة فوق التطبيق الموجود بعد إنهاء المشوار، دون حذف التطبيق أو مسح بياناته.

النتيجة النهائية: نجحت الأهداف الستة معًا خلال 5 دقائق و3 ثوانٍ؛ 241 اختبارًا لكل نكهة دون إخفاق أو تخطٍّ، وصفر أخطاء lint مع 49 تحذيرًا سابقًا لكل نكهة ودون تحذير جديد. نجح توقيع النكهتين ومحاذاة 16KB ومقارنة الهوية بمخرجات 6.4. لا يوجد اختبار تثبيت على هاتف فعلي.
