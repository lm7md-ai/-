# تحميل التطبيق

[تحميل مشواري 2.0 للأندرويد (APK، نحو 58 ميجابايت)](https://raw.githubusercontent.com/m7mdxzx9/-/main/releases/app-v2.0.apk)

هذه نسخة اختبار موقعة، تتطلب Android 8 أو أحدث. تشمل واجهة جديدة فاتحة وداكنة،
البحث والمفضلة والملاحظات، ميزانية الشهر ورسم المصاريف، استعراض المسار زمنيًا،
تصدير GPX/CSV ونسخًا محليًا، مع الخريطة دون إنترنت واستيراد مشتريات الرسائل.

**الملف الأساسي 2.0 تحديث مباشر لملف 1.3 المنشور هنا.** أنهِ المشوار الجاري،
ثم ثبّته فوق 1.3 دون إزالة التطبيق أو مسح بياناته. الاسم يبقى **مشواري**،
وتُحفظ المشاوير والمصاريف عبر ترحيل قاعدة البيانات. التوقيع مطابق لملف 1.3؛
لا حاجة لنقل البيانات بين تطبيقين إذا كنت تستخدمه بالفعل.

إذا ما زلت على النسخة الأولى التي يظهر معها تعارض الحزم، يتوفر
[ملف 2.0 مستقل](https://raw.githubusercontent.com/m7mdxzx9/-/main/releases/app-v2.0-independent.apk)
بهوية مختلفة للتثبيت بجانب القديم. هذا البديل لا يقرأ بيانات القديم تلقائيًا
ويحتاج إلى نقل محلي. لا تستخدمه بدل الملف الأساسي إن كنت تريد تحديث 1.3.

[تحميل أداة النقل لويندوز (ZIP، نحو 18 ميجابايت)](https://raw.githubusercontent.com/m7mdxzx9/-/main/releases/mashwari-transfer-windows.zip)

اتبع [دليل النقل باستخدام USB](../android/docs/WINDOWS_MIGRATION.md): استخرج الحزمة،
وصل الهاتف وفعّل تصحيح USB، شغّل `START-TRANSFER.cmd`، ثم استورد ملف التنزيلات
في 2.0. لا تحتاج إلى تثبيت Python أو كتابة أوامر. يتوفر أيضًا
[بديل من الهاتف فقط](../android/docs/PHONE_MIGRATION.md).
